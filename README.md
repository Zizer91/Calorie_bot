# 🏠 Бот поиска квартиры в Санкт-Петербурге

Каждые ~20 минут проверяет **ЦИАН, Авито, ДомКлик, Яндекс Недвижимость, Этажи и N1**,
отбирает подходящие квартиры и присылает в Telegram ссылку и краткое описание.
**Повторов не шлёт:** ни одно и то же объявление, ни ту же квартиру, выложенную на другом сайте.

## Критерии (по умолчанию, меняются в `settings.env`)

| Параметр | Значение |
|---|---|
| Цена | до 11,8 млн ₽ |
| Комнаты | 2-к и 3-к; 1-к — только с кухней от 12 м² и площадью от 36 м² (под кухню-гостиную + спальню); евро-2 тоже подходит |
| Дом | кирпич, монолит-кирпич, сталинка — да; панель/блок — только с 1970 г.; монолит и дерево — нет |
| Метро | не больше 15 минут пешком |

Если сайт не указал тип дома, объявление всё равно придёт, но с пометкой ⚠️
(отключается: `ALLOW_UNKNOWN_BUILDING=false`).

Пример сообщения:
```
🏠 1-к, 42 м², 4/9 эт.
💰 11 200 000 ₽ (266 667 ₽/м²)
🍳 кухня 15 м² · 🧱 панель, 1985 г.
🚇 Звёздная, 9 мин пешком
📍 улица Ленсовета, 81
🔗 ЦИАН
```

## Установка

1. Python 3.10+.
2. Создайте бота у [@BotFather](https://t.me/BotFather) и получите токен.
   Узнайте свой chat_id у [@userinfobot](https://t.me/userinfobot).
   Напишите своему боту `/start`, иначе он не сможет вам писать.
3. Установите и настройте:
   ```bash
   python -m venv .venv && source .venv/bin/activate
   pip install -r requirements.txt
   ```
   Скопируйте файл `settings.env.example` в `settings.env` (рядом, в той же папке)
   и впишите в него токен и chat_id.
   (Старое имя `.env` тоже работает.)
4. Проверка без Telegram (печатает в консоль, базу не трогает):
   ```bash
   python -m flat_bot --dry-run --sources cian
   ```
5. Запуск:
   ```bash
   python -m flat_bot            # работает постоянно, проверка каждые INTERVAL_MIN минут
   python -m flat_bot --once     # один проход (удобно для cron)
   ```

Запускайте на домашнем компьютере или сервере в России: некоторые из этих сайтов
плохо отвечают на запросы с зарубежных IP.

### Автозапуск через cron (каждые 20 минут)
```
*/20 * * * * cd /path/to/Calorie_bot && .venv/bin/python -m flat_bot --once >> bot.log 2>&1
```

## Как устроено

```
flat_bot/
  sources/       по модулю на сайт: cian (JSON API), domclick (JSON API),
                 yandex (JSON из страницы), avito (HTML), etagi и n1 (общий HTML-парсер)
  extract.py     извлечение площади, кухни, этажа, типа дома, года и метро из русского текста
  filters.py     критерии отбора
  storage.py     SQLite: что видели, что отправили, состояние источников
  runner.py      один проход: сбор → уточнение → фильтр → защита от повторов → отправка
  notifier.py    Telegram
```

* В карточках выдачи Авито, Этажей и N1 нет кухни и типа дома. Бот открывает страницу
  объявления, но только для тех, что уже прошли по цене, комнатам и метро
  (не больше `MAX_DETAILS_PER_SOURCE` за проход).
* **Защита от повторов.** Отправленное объявление (сайт + id) запоминается навсегда.
  Отклонённое тоже, но перепроверяется, если у него изменилась цена.
  Одна квартира на разных сайтах узнаётся по совпадению комнат, этажа, этажности,
  площади (±0,6 м²), цены (±7 %), номера дома и станции метро.
* Если сайт 3 проверки подряд ничего не отдаёт, бот один раз предупредит в Telegram
  и сообщит, когда сайт снова заработает.
* `NOTIFY_PRICE_DROP=true` — присылать, когда у уже отправленной квартиры падает цена.

## Если какой-то сайт перестал работать

Сайты регулярно меняют вёрстку, поэтому парсеры иногда приходится чинить.
1. Включите `DEBUG_DIR=debug`, запустите `python -m flat_bot --dry-run --sources avito -v`
   и посмотрите сохранённые страницы в `debug/`.
2. Если сайт отвечает ошибками, увеличьте `DELAY_MIN/MAX` и уменьшите `PAGES_PER_SOURCE`.
3. Можно временно убрать сайт из `SOURCES`.
4. Если N1 не работает по Петербургу (основные города N1 — Новосибирск, Екатеринбург и др.),
   уберите `n1` из `SOURCES` или укажите нужный адрес в `N1_URL`.
